# Utazási kanonikus helyadatok

Ez a könyvtár a Gitben verziózott, ember által jóváhagyott helyismeretet tartja.

Az `places/beaches.json` és a `places/restaurants.json` az `utazasi_data_codex_v1.1` csomagból került be. Az
eredeti stabil `id` mezők megmaradtak; a `slug` mezők ezekből, adatvesztés és
tartalmi kiegészítés nélkül, a frontend olvasható kulcsaként készültek.

A Supabase későbbi runtime-adatbázis; nem helyettesíti ezt a kanonikus forrást.
